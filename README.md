main.py will ask the user for a file they want to check.
The selected file will then go through checks to extract some data from the file.
The extracted data will be validated using regex in the other validation files.
All the extracted data will be written in different files, all specific to data extracted.

REQUIREMENTS

Have python installed in your device.

HOW TO USE IT?

1. Clone this repository on your device.
2. Change directory to this repository.
3. Write the file you want to extract the data from.
4. Use the code "python3 main.py".
5. The computer will ask you to put a file name.
6. The code will run and files will be added to the repository that represent the different data extracted.
